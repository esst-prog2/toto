## Variables, types and measured missingness

CSV is text on disk. `data.validate_historical_data` converts date to timezone-naive pandas datetime, goals to int64, season/team labels to strings and derives string result 1/X/2. Synthetic history has the six required columns `season,date,home_team,away_team,home_goals,away_goals`. Adapted real history has those plus categorical `source_division,dataset_role` and three decimal bookmaker odds (`bookmaker_home_odds,bookmaker_draw_odds,bookmaker_away_odds`). Odds are serialized decimal strings by the adapter and parse as floats with pandas; predictor ignores them. No cells are blank in either history CSV or sample ticket. No repeated `(date,home_team,away_team)` keys were found in either history CSV. This is not a universal event-identity check.

Each original has 106 columns. Full exact headers are reproducible with the snippet below. Variable groups are:

- Categorical/text: Div, HomeTeam, AwayTeam, FTR, HTR, Referee; Date day-first and Time HH:MM. No timezone or result-publication timestamp. Source division IDs identify competitions; no persistent club IDs.
- Integer-valued match records: FTHG/FTAG, HTHG/HTAG; home/away shots HS/AS, on-target HST/AST, fouls HF/AF, corners HC/AC, yellows HY/AY and reds HR/AR. These are post-match measurements.
- Decimal prices: bookmaker H/D/A columns for Bet365, BW, IW, PS, WH, VC and market Max/Avg, including C-prefixed closing prices; over/under 2.5 and Asian handicap prices, handicap lines AHh/AHCh. Prices and lines have different meanings and should not be conflated.

## Standardized structure and identity

`src/toto_estimator/historical_import.py:22,128` defines exact canonical columns:

```text
match_id,date,league,season,home_team,away_team,home_goals,away_goals
```

Dates are ISO days; seasons canonical YYYY or consecutive YYYY/YYYY; goals nonnegative integers. match_id is SHA-256 of compact UTF-8 JSON `[league,season,date,home_team,away_team]`. It identifies a fixture, not a team; no universal team_id is available. Source metadata is explicit, not inferred from filenames. Exact duplicates collapse within an import; score conflicts exclude all versions; unscored fixtures are counted separately. Same-day replays with identical identity cannot be separated automatically. Runtime history lacks league-aware grouping even when extra league columns survive validation.

The canonical schema omits odds, kickoff time, stage, round, result status, initial/completion dates, publication dates, reported versus accepted goals, licensing and lineage. Those belong in linked manifests/archives/sidecars. Loading the CSV alone cannot enforce their restrictions.

## Historical semantics and readiness gates

The current retrospective policy in `docs/accelerated-five-phase-workflow.md:Operating contract` uses original football dates and accepted final results, including later adjudications, without administrative-publication-date filtering. Preserve initial kickoff and completion dates separately; no-kickoff awards are NOT_PLAYED. This policy is respected here, not replaced with a forecasting filter.

Earlier La Liga/Ligue 1/Ligue 2/Eredivisie/Primeira reports describe completion/availability dates and conservative chronological guards. Other archives retain awarded results with exclusion sidecars. This is a real semantic heterogeneity, not safely resolved by concatenating CSVs or treating all date fields as original kickoff dates. Without the private manifests, it cannot be established which earlier outputs were subsequently migrated. Any future model must declare the retrospective versus real-time objective and inspect the actual policy versions before selecting records.

No local raw source or adapted schema explicitly encodes administrative status, extra-time goals, shootout scores or time of result availability. England league files use FTHG/FTAG and the adapter checks their outcome consistency; no code converts a shootout winner into a 1/X/2 label. Across broader staged/playoff competitions, the eight-column schema cannot establish regulation-time suitability. Inspect source-specific annotations and approved sidecars; do not infer a draw or full-time target from a penalty winner or an awarded score. `docs/ligue-1-standardization.md` explicitly holds a penalty/administrative ambiguity. No extra-time or shootout review of unavailable private originals can be claimed.

Acquired means bytes and provenance exist; standardized means projected to the common schema; validated may mean structural consistency, bounded external evidence or independent reconstruction (different guarantees); modelling-ready additionally requires objective-specific targets, chronology, identities, missingness handling and intended-use permission. Local spike is reproducible technical benchmark data, not cleared here for new training. Reports retain unresolved upstream rights, academic/noncommercial limits and, for some Football-Data uses, explicit AI-training restrictions. No new rights inquiry or legal conclusion was made. These are existing project restrictions, not invented approval gates.

## Reproduce the local inventory without writing data

Run from this worktree with existing Python; no dependencies needed:

```sh
python3 -B - <<'PY'
from pathlib import Path
import csv, hashlib
from collections import Counter
from datetime import datetime
for p in sorted(Path('data').rglob('*')):
    if not p.is_file():
        continue
    b = p.read_bytes()
    print(p, len(b), hashlib.sha256(b).hexdigest())
    if p.suffix != '.csv':
        continue
    rows = list(csv.DictReader(b.decode('utf-8-sig').splitlines()))
    columns = list(rows[0])
    print('rows', len(rows), 'columns', columns)
    print('blanks', {c: sum(not r[c].strip() for r in rows)
                     for c in columns if any(not r[c].strip() for r in rows)})
    for c in ('season', 'source_division', 'dataset_role'):
        if c in columns:
            print(c, dict(Counter(r[c] for r in rows)))
    for c, fmt in (('date', '%Y-%m-%d'), ('Date', '%d/%m/%Y')):
        if c in columns:
            dates = [datetime.strptime(r[c], fmt).date() for r in rows]
            print('coverage', min(dates), max(dates))
    if 'date' in columns and 'home_team' in columns:
        keys = [(r['date'], r['home_team'], r['away_team']) for r in rows]
        print('repeated dated pair keys', len(keys)-len(set(keys)))
print('private present', Path('data/private').exists())
PY
```
